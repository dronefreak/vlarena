# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems. Use GitHub's private
vulnerability reporting instead: **Security → Report a vulnerability** on
[github.com/dronefreak/vlarena](https://github.com/dronefreak/vlarena/security).

If private reporting is unavailable, email [kumaar324@gmail.com](mailto:kumaar324@gmail.com).

Include what you found, how to reproduce it, and the affected commit. You'll get an
acknowledgement as soon as possible.

## Scope

vlarena is a research/visualisation tool. It is **not** a driving system: model
outputs must never be used to control a vehicle.

Vulnerabilities in the upstream models or their code (`third_party/`) should be
reported to those projects directly.
